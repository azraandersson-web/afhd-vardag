# ADHD Vardag – iPhone webbapp

Det här är en fristående PWA (Progressive Web App) som kan installeras på iPhone via Safari.

## Vad som finns i versionen
- Idag-lista med egna uppgifter
- Rutiner och små städuppgifter
- Enkel kalender
- Dagens köp och summering
- Sparmål
- Räkningskoll
- Brain dump
- Rökfri resa med stoppdatum 10 september 2026
- Sparande från rökstopp baserat på dagskostnad
- "Jag är röksugen"-pepp
- "Jag har fastnat"-läge
- Lokal lagring i Safari
- Offline-stöd efter första laddningen
- Export av data till JSON

## Viktigt om iPhone
För att kunna lägga appen på hemskärmen som en riktig PWA behöver filerna ligga på en webbplats med HTTPS.
Du kan t.ex. använda GitHub Pages, Netlify, Cloudflare Pages eller annan statisk hosting.

När sidan är publicerad:
1. Öppna adressen i Safari på iPhone.
2. Tryck Dela.
3. Välj "Lägg till på hemskärmen".
4. Starta sedan ADHD Vardag från ikonen.

Dina uppgifter sparas lokalt på enheten i webbläsarens lagring. Rensa inte webbplatsdata för sidan om du vill behålla informationen. Använd "Exportera mina data" ibland som backup.
